# QA-Basic-React


This is a **React-based interactive quiz app** designed for **new developers** to practice fundamental programming concepts.  
It’s inspired by the original **[C# .NET console version](https://github.com/VJay114/dotnet-QA-Console)**, but rebuilt with a **modern web interface** for better engagement and accessibility.


---

## 🧠 About the Project

The goal of this project is to help **beginner developers** learn through interactive question-and-answer sessions.  
Each question presents **multiple choices**, validates user input, and provides a final score at the end — all within a simple and friendly UI.

This project serves as both:
- 🧩 A **learning exercise** in React and JavaScript fundamentals  
- 🎓 A **training tool** for onboarding new developers in your team

---

## 🚀 Features

- Displays questions one at a time with numbered labels  
- Multiple-choice selection with real-time validation  
- Prevents skipping questions without choosing an answer  
- Calculates total score and shows feedback (Perfect, Good, Keep practicing)  
- Restart option to retry the quiz  
- Clean component-based React structure  
- Beginner-friendly code comments and styling  

---

## 🧩 Technologies Used

- ⚛️ **React (Vite or CRA)**  
- 💅 **CSS for basic styling**  
- 🧠 **JavaScript ES6 features**
